                Colour scheme

          Speech
          
              
              
              
          Dictation uses Windows speech recognition (the same as Win+H): choose Dictate in a note's More menu, or press Ctrl+Shift+D with the cursor in a note, then speak. The first time, Windows may ask to turn on online speech recognition.

          Vaults
          
              
          A vault is a folder on this computer whose Markdown files are notes. If it is a git repository with a remote, changes are committed, pulled and pushed automatically, so the same notes follow you to other computers.

          Links your CLAUDE.md, AGENTS.md, Claude commands, output styles and memory notes as editable notes in an "Agent files" folder. Edits write straight to the real files.
